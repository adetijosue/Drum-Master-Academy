# Drum Master Academy - Assets Documents

Ce dossier est destiné à stocker tous les documents pédagogiques et ressources pour les cours en ligne de la DMA.

## Structure du dossier
- `/pdf` : Rapports de formation, syllabus, et documents administratifs.
- `/scores` : Partitions (PDF, images, fichiers MusicXML).
- `/guides` : Méthodes de travail, guides de configuration de matériel, etc.

## Formats recommandés
- **PDF** pour une compatibilité maximale.
- **Images haute résolution** pour les extraits de partitions.
- **Archives ZIP** pour les bundles de ressources.
